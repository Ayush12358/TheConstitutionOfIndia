## 4. Notes / source-selection decisions

- Act primary sources per the task: legislative.gov.in first, then indiacode.nic.in, then the Gazette of
  India (egazette.gov.in) as the official publication. 99/102/103/105/106 acts come from legislative.gov.in
  static uploads; 100/101/104 from egazette.gov.in (Gazette Extraordinary); 97/98 from indiacode.nic.in
  via the Wayback Machine (the live indiacode files are dead — 404 — so the archived copies of the same
  authoritative URLs were used).
- Bills: PRS India hosts the Parliament bill PDFs under prsindia.org/files/bills_acts/... — used for all 10.
- The old legislative.gov.in URL for the 105th Act (sites/default/files/CONSTITUTION (ONE HUNDRED AND FIFTH
  AMENDMENT) ACT, 2021_1.pdf) is dead (404); the site's current listing uses /static/uploads/ hashes.
- 106th bill: PRS's page also links a cdnbbsr.s3waas.gov.in file (2023050195.pdf) that is NOT the bill
  (it is a 404-page Constitution of India booklet) — the correct bill is the "Bill Text" PDF listed above.
- All scanned/image PDFs (98 Act, 102/103/105 Acts, 98/106 Bills) were OCR-verified page 1–2 with a vision
  model; every title/date matched the expected amendment.
- Verification artifacts: AMENDMENTS/manifest.json records the final URL + size per file.
